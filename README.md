# Lumeo scorecards

Weekly creative scorecards for the Lumeo team, served by GitHub Pages.

- `data.json` is rewritten every Monday by the Make scenario "Lumeo: Weekly Meta pull + ClickUp sync v2". Don't edit it by hand.
- `picks.json` holds manual attribution (CS / editor) for older ads that aren't tracked through ClickUp. Key = exact Meta ad name.
- `index.html`, `style.css`, `app.js` are the page. Week / Month / Lifetime use the same verdict rules.
